### 1. 做多与做空

可以把 **做多（Long）** 和 **做空（Short）** 先理解成一句最简单的话：

> 做多：我认为它会涨，先买后卖。
> 做空：我认为它会跌，先卖后买。

关键区别就在于：**你到底是先买，还是先卖。**

#### 1. 做多：低买高卖

假设现在一股股票是 100 元。

你认为它会涨，于是：

```
现在：100 元
  ↓
买入 1 股
  ↓
上涨到 120 元
  ↓
卖出
```

你赚：

```
120 - 100 = 20 元
```

这就是**做多**。

**做多的本质**

你实际上是在押注：

> 未来价格 > 当前价格

公式可以简单写成：

```
做多收益 = 卖出价格 - 买入价格
```

所以：

|股票价格 | 你的结果 |
| --------: | ---: |
| 100 → 120 |  +20 |
|  100 → 80 |  -20 |
|  100 → 50 |  -50 |

#### 2. 做空：先卖后买

做空一开始比较反直觉，因为：

> “我手里都没有股票，怎么卖？”

答案是：借来卖。

还是假设股票现在：

```
100 元/股
```

你认为它会跌，于是从券商那里**借 1 股**。

然后：

```
借 1 股
  ↓
100 元卖掉
  ↓
得到 100 元现金
  ↓
股票跌到 60 元
  ↓
花 60 元买回 1 股
  ↓
把这 1 股还给券商
```

你的利润：

```
100 - 60 = 40 元
```

这就是做空。

#### 3. 为什么“先卖”还能赚钱？

这里是理解做空最关键的地方。

你可以把它理解成：

> 先借东西卖掉，等它降价以后再买回来还。

比如：

```
你借朋友一台电脑

电脑现在值 10,000 元
        ↓
你把电脑卖掉
得到 10,000 元
        ↓
过几天电脑跌到 7,000 元
        ↓
你花 7,000 元买一台同样的电脑
        ↓
还给朋友
```

你手里剩：

```
10,000 - 7,000 = 3,000 元
```

所以做空实际上就是：

> **借资产 → 高价卖出 → 低价买回 → 归还资产**

#### 4. 做多和做空放在一起

这是最重要的一张表：

|      | 做多      | 做空       |
| ---- | ------- | -------- |
| 判断   | 看涨 📈   | 看跌 📉    |
| 第一动作 | 买       | 卖        |
| 第二动作 | 卖       | 买        |
| 赚钱条件 | 后面涨     | 后面跌      |
| 简单理解 | 低买高卖    | 高卖低买     |
| 收益   | 卖价 - 买价 | 卖价 - 买回价 |

可以记成：

```
做多：

买 → 涨 → 卖
↓
赚钱

做空：

借 → 卖 → 跌 → 买 → 还
↓
赚钱
```

#### 5. 一个特别重要的区别：风险

这里开始就有意思了。

**做多**

假设你用 100 元买股票。

最坏情况：

```
股票跌到 0
```

你最多亏：

```
100 元
```

所以做多理论上的最大亏损是：

> **本金全部归零。**

但上涨理论上没有上限：

```
100 → 200 → 500 → 1000 → ...
```

所以：

> **做多：亏损有限，收益理论上无限。**

**做空**

假设你借股票的时候价格是 100 元。

如果股票跌到 50：

```
赚 50
```

如果跌到 0：

```
最多赚 100
```

但如果股票涨了呢？

```
100 → 200
```

你需要：

```
200 元买回来
```

亏：

```
200 - 100 = 100
```

如果涨到：

```
500
```

你亏：

```
500 - 100 = 400
```

如果涨到：

```
1000
```

你亏：

```
900
```

理论上股票价格可以不断上涨。

所以：

> **做空：收益有限，亏损理论上无限。**

这也是为什么做空通常比单纯买入风险更复杂。

#### 6. 为什么金融市场允许做空？

因为做空可以让市场不仅有：

> “认为它会涨的人”

还有：

> “认为它会跌的人”。

比如一家公司真实价值可能只有：

```
50 元
```

但是市场炒到了：

```
200 元
```

如果所有人只能买：

```
大家只能：
买买买
```

价格可能继续被推高。

但如果允许做空：

```
认为它值 50 元的人
        ↓
做空
        ↓
卖出
        ↓
市场出现卖压
```

做空者实际上也在提供一种**价格发现机制**。

当然，做空也可能带来市场操纵、挤空等问题，所以不同市场对做空有很多限制。

#### 7. “做多/做空”不等于“买股票/卖股票”

这个区别非常重要。

普通人说：

> “我卖股票了。”

不一定是在做空。

比如：

```
我之前 50 元买入
现在 100 元卖掉
```

这是：

> **平多仓**

而不是做空。

真正的做空是：

```
我原来没有股票
↓
借股票
↓
卖掉
↓
未来买回来
```

所以可以把交易拆成：

```
             建仓
              │
       ┌──────┴──────┐
       ↓             ↓
      做多           做空
       │             │
      买入           卖出
       │             │
       ↓             ↓
     持有股票       持有空头仓位
       │             │
       ↓             ↓
      卖出           买回
       │             │
       ↓             ↓
     平多仓         平空仓
```

#### 8. 再进一步理解：“仓位”

你以后看股票、期货、加密货币时，经常会看到：

- 多头
- 空头
- 多仓
- 空仓
- 开多
- 平多
- 开空
- 平空

其实可以统一理解。

**开多**

```
我认为涨
↓
买入
↓
建立多仓
```

**平多**

```
我之前做多
↓
现在卖掉
↓
关闭多仓
```

**开空**

```
我认为跌
↓
卖出/建立空头
↓
建立空仓
```

**平空**

```
我之前做空
↓
现在买回来
↓
关闭空仓
```

所以：

> “开” = 建立一个方向上的仓位
>
> “平” = 把这个仓位关闭

#### 9. 用一句非常直观的话记住

你可以把市场价格想象成电梯：

```
              📈
             涨
              ↑
        做多：赚
        做空：亏
              │
            价格
              │
              ↓
             跌
              📉
        做多：亏
        做空：赚
```

所以最核心的理解就是：

> 做多 = 押上涨，先买后卖。
>
> 做空 = 押下跌，先卖后买。

### 2. 古文观止 - 郑庄公戒饬守臣

秋七月，公会齐侯、郑伯<sup id="w118f1-1">[[1]](#w118a1-1)</sup>伐许<sup id="w118f1-2">[[2]](#w118a1-2)</sup>。庚辰，傅<sup id="w118f1-3">[[3]](#w118a1-3)</sup>于许。颍考叔取郑伯之旗蝥弧<sup id="w118f1-3">[[3]](#w118a1-3)</sup>以先登，子都<sup id="w118f1-4">[[4]](#w118a1-4)</sup>自下射之，颠。瑕叔盈<sup id="w118f1-5">[[5]](#w118a1-5)</sup>又以蝥弧登，周麾而呼曰：“君登矣！”郑师毕登。壬午，遂入许。许庄公奔卫。齐侯以许让公。公曰：“君谓许不共<sup id="w118f1-6">[[6]](#w118a1-6)</sup>，故从君讨之。许既伏其罪矣。虽君有命，寡人弗敢与闻。”乃与郑人。

> 鲁隐公十一年秋天七月，鲁隐公会合齐侯、郑伯讨伐许国。初一这一天，三国的军队逼近许国城下。颍考叔举着郑国的蝥弧旗，首先登上了城墙，子都从下面射他，颍考叔跌下来死了。瑕叔盈又举起蝥弧爬上城墙，挥舞旗帜并呼喊道：“我们国君登城啦！”郑国的军队全部登上城墙。初三这一天，便攻入许国。许庄公逃到卫国去了。齐侯要把许国让给鲁隐公。鲁隐公说：“您说许国不交纳贡物，又不履行诸侯的职责，所以跟随您讨伐它。现在许国已经受到应有的惩罚了，虽然您有命令，我也不敢参与这事的。”于是就把许国给了郑庄公。

郑伯使许大夫百里<sup id="w118f1-7">[[7]](#w118a1-7)</sup>奉许叔<sup id="w118f1-8">[[8]](#w118a1-8)</sup>以居许东偏，曰：“天祸许国，鬼神实不逞于许君，而假手于我寡人，寡人唯是一二父兄不能共亿<sup id="w118f1-9">[[9]](#w118a1-9)</sup>，其敢以许自为功乎？寡人有弟，不能和协，而使糊其口于四方，其况能久有许乎？吾子<sup id="w118f1-10">[[10]](#w118a1-10)</sup>其奉许叔以抚柔此民也，吾将使获<sup id="w118f1-11">[[11]](#w118a1-11)</sup>也佐吾子。若寡人得没于地，天其以礼悔祸于许，无宁兹许公复奉其社稷，唯我郑国之有请谒焉，如旧昏媾<sup id="w118f1-12">[[12]](#w118a1-12)</sup>，其能降以相从也。无滋他族实逼处此，以与我郑国争此土也。吾子孙其覆亡之不暇，而况能禋祀<sup id="w118f1-13">[[13]](#w118a1-13)</sup>许乎？寡人之使吾子处此，不惟许国之为，亦聊以固吾圉<sup id="w118f1-14">[[14]](#w118a1-14)</sup>也。”

> 郑庄公让许国大夫百里侍奉许庄公的弟弟许叔住在许国的东部边邑，对他说：“上天降祸给许国，鬼神也不满意许君，所以借我的手来惩罚他，我有少数的几个同姓臣子，尚且不能同心协力，哪里还敢拿打败许国作为自己的功劳呢？我有个弟弟(共叔段)，还不能和睦相处，致使他到处流浪，在四方奔走寄食，又怎么能长久占有许国呢？你侍奉许叔安抚这里的百姓，我将派公孙获来帮助你。如果我能得到善终而长眠于地下，上天施恩，懊悔前日对许的降祸，难道许公就不能再来掌管他的国家？只是我们郑国请求时，希望相亲相近像老亲家一样，能屈尊降贵答应我们。千万不要助长他族，使他族逼近、居住在这里，来和我郑国争夺这地方。如果那样，我的子孙连自己挽救郑国自己的危亡都无暇照顾，又怎能祭祀许国的山川呢？我之所以让你住在这里，不单是为许国着想，也借以巩固我们郑国的边防啊。”

乃使公孙获处许西偏，曰：“凡而<sup id="w118f1-16">[[16]](#w118a1-16)</sup>器用财贿<sup id="w118f1-17">[[17]](#w118a1-17)</sup>，无置于许。我死，乃<sup id="w118f1-18">[[18]](#w118a1-18)</sup>亟<sup id="w118f1-15">[[15]](#w118a1-15)</sup>去之！吾先君新邑于此，王室而既卑矣，周之子孙日失其序<sup id="w118f1-19">[[19]](#w118a1-19)</sup>。夫许，大岳<sup id="w118f1-20">[[20]](#w118a1-20)</sup>之胤<sup id="w118f1-21">[[21]](#w118a1-21)</sup>也。天而既厌周德矣，吾其能与许争乎？”

> 于是又派公孙获驻扎在许国西部边境，对他说：“凡是你的器物钱财，不要放在许国。我死了，你就马上离开许国！先君是新近在这里建成都邑，眼看周王室的地位权力一天天衰微，周的子孙也一天天的失掉所继承的祖先功业。许国是太岳后代。上天既然厌弃周朝的气运了，我们是周的子孙，怎么能和许国相争呢？”

君子谓郑庄公“于是乎有礼。礼，经<sup id="w118f1-22">[[22]](#w118a1-22)</sup>国家，定社稷，序民人，利后嗣者也。许，无刑而伐之，服而舍之，度德而处之，量力而行之，相时而动，无累后人，可谓知礼矣。”

> 君子认为：“郑庄公在这件事上是符合礼制的。礼制，是可以治理国家，稳定政权，安抚百姓，并有利于后世子孙的。许国不守法度就去讨伐它，伏罪了就宽恕它，度量自己的德行去处理问题，估量自己的实力去行事，看清形势而后行动，不连累后人，可以说是知礼了。”
