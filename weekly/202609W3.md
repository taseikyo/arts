### 1. 做多与做空

可以把 **做多（Long）** 和 **做空（Short）** 先理解成一句最简单的话：

> 做多：我认为它会涨，先买后卖。
> 做空：我认为它会跌，先卖后买。

关键区别就在于：**你到底是先买，还是先卖。**

#### 1. 做多：低买高卖

假设现在一股股票是 100 元。

你认为它会涨，于是：

```
现在：100 元
  ↓
买入 1 股
  ↓
上涨到 120 元
  ↓
卖出
```

你赚：

```
120 - 100 = 20 元
```

这就是**做多**。

**做多的本质**

你实际上是在押注：

> 未来价格 > 当前价格

公式可以简单写成：

```
做多收益 = 卖出价格 - 买入价格
```

所以：

|股票价格 | 你的结果 |
| --------: | ---: |
| 100 → 120 |  +20 |
|  100 → 80 |  -20 |
|  100 → 50 |  -50 |

#### 2. 做空：先卖后买

做空一开始比较反直觉，因为：

> “我手里都没有股票，怎么卖？”

答案是：借来卖。

还是假设股票现在：

```
100 元/股
```

你认为它会跌，于是从券商那里**借 1 股**。

然后：

```
借 1 股
  ↓
100 元卖掉
  ↓
得到 100 元现金
  ↓
股票跌到 60 元
  ↓
花 60 元买回 1 股
  ↓
把这 1 股还给券商
```

你的利润：

```
100 - 60 = 40 元
```

这就是做空。

#### 3. 为什么“先卖”还能赚钱？

这里是理解做空最关键的地方。

你可以把它理解成：

> 先借东西卖掉，等它降价以后再买回来还。

比如：

```
你借朋友一台电脑

电脑现在值 10,000 元
        ↓
你把电脑卖掉
得到 10,000 元
        ↓
过几天电脑跌到 7,000 元
        ↓
你花 7,000 元买一台同样的电脑
        ↓
还给朋友
```

你手里剩：

```
10,000 - 7,000 = 3,000 元
```

所以做空实际上就是：

> **借资产 → 高价卖出 → 低价买回 → 归还资产**

#### 4. 做多和做空放在一起

这是最重要的一张表：

|      | 做多      | 做空       |
| ---- | ------- | -------- |
| 判断   | 看涨 📈   | 看跌 📉    |
| 第一动作 | 买       | 卖        |
| 第二动作 | 卖       | 买        |
| 赚钱条件 | 后面涨     | 后面跌      |
| 简单理解 | 低买高卖    | 高卖低买     |
| 收益   | 卖价 - 买价 | 卖价 - 买回价 |

可以记成：

```
做多：

买 → 涨 → 卖
↓
赚钱

做空：

借 → 卖 → 跌 → 买 → 还
↓
赚钱
```

#### 5. 一个特别重要的区别：风险

这里开始就有意思了。

**做多**

假设你用 100 元买股票。

最坏情况：

```
股票跌到 0
```

你最多亏：

```
100 元
```

所以做多理论上的最大亏损是：

> **本金全部归零。**

但上涨理论上没有上限：

```
100 → 200 → 500 → 1000 → ...
```

所以：

> **做多：亏损有限，收益理论上无限。**

**做空**

假设你借股票的时候价格是 100 元。

如果股票跌到 50：

```
赚 50
```

如果跌到 0：

```
最多赚 100
```

但如果股票涨了呢？

```
100 → 200
```

你需要：

```
200 元买回来
```

亏：

```
200 - 100 = 100
```

如果涨到：

```
500
```

你亏：

```
500 - 100 = 400
```

如果涨到：

```
1000
```

你亏：

```
900
```

理论上股票价格可以不断上涨。

所以：

> **做空：收益有限，亏损理论上无限。**

这也是为什么做空通常比单纯买入风险更复杂。

#### 6. 为什么金融市场允许做空？

因为做空可以让市场不仅有：

> “认为它会涨的人”

还有：

> “认为它会跌的人”。

比如一家公司真实价值可能只有：

```
50 元
```

但是市场炒到了：

```
200 元
```

如果所有人只能买：

```
大家只能：
买买买
```

价格可能继续被推高。

但如果允许做空：

```
认为它值 50 元的人
        ↓
做空
        ↓
卖出
        ↓
市场出现卖压
```

做空者实际上也在提供一种**价格发现机制**。

当然，做空也可能带来市场操纵、挤空等问题，所以不同市场对做空有很多限制。

#### 7. “做多/做空”不等于“买股票/卖股票”

这个区别非常重要。

普通人说：

> “我卖股票了。”

不一定是在做空。

比如：

```
我之前 50 元买入
现在 100 元卖掉
```

这是：

> **平多仓**

而不是做空。

真正的做空是：

```
我原来没有股票
↓
借股票
↓
卖掉
↓
未来买回来
```

所以可以把交易拆成：

```
             建仓
              │
       ┌──────┴──────┐
       ↓             ↓
      做多           做空
       │             │
      买入           卖出
       │             │
       ↓             ↓
     持有股票       持有空头仓位
       │             │
       ↓             ↓
      卖出           买回
       │             │
       ↓             ↓
     平多仓         平空仓
```

#### 8. 再进一步理解：“仓位”

你以后看股票、期货、加密货币时，经常会看到：

- 多头
- 空头
- 多仓
- 空仓
- 开多
- 平多
- 开空
- 平空

其实可以统一理解。

**开多**

```
我认为涨
↓
买入
↓
建立多仓
```

**平多**

```
我之前做多
↓
现在卖掉
↓
关闭多仓
```

**开空**

```
我认为跌
↓
卖出/建立空头
↓
建立空仓
```

**平空**

```
我之前做空
↓
现在买回来
↓
关闭空仓
```

所以：

> “开” = 建立一个方向上的仓位
>
> “平” = 把这个仓位关闭

#### 9. 用一句非常直观的话记住

你可以把市场价格想象成电梯：

```
              📈
             涨
              ↑
        做多：赚
        做空：亏
              │
            价格
              │
              ↓
             跌
              📉
        做多：亏
        做空：赚
```

所以最核心的理解就是：

> 做多 = 押上涨，先买后卖。
>
> 做空 = 押下跌，先卖后买。

### 3. 古文观止 - 臧哀伯谏纳郜鼎

夏四月，取郜<sup id="w118g1-1">[[1]](#w118b1-1)</sup>大鼎于宋，纳于大庙<sup id="w118g1-2">[[2]](#w118b1-2)</sup>，非礼也。

> 夏四月，鲁桓公从宋国取得原属郜国的传国大鼎，放进太庙，这是不符合礼仪的。

- <b id="w118b1-1">[[1]](#w118g1-1)</b> 郜（ɡào）：国名，姬姓，开国国君是周文王的一个庶子，春秋时为宋国所灭，其故地在今山东成武县东南。鼎：古代的一种烹饪器物，又因常常用作旌功记绩的礼器，所以又作为传国重器，其形制一般为三足两耳。宋：国名，春秋时为十二诸侯之一，开国国君为殷纣王的庶兄微子，其地在今河南东部及山东、江苏和安徽三省之间。
- <b id="w118b1-2">[[2]](#w118g1-2)</b> 大（tài）庙：即太庙，天子或诸侯国国君的祖庙。

臧哀伯谏曰：“君人者，将昭德<sup id="w118g1-4">[[4]](#w118b1-4)</sup>塞违，以临照<sup id="w118g1-3">[[3]](#w118b1-3)</sup>百官；犹惧或失之，故昭令德以示子孙。是以清庙<sup id="w118g1-5">[[5]](#w118b1-5)</sup>茅屋，大路越席<sup id="w118g1-6">[[6]](#w118b1-6)</sup>，大羹不致<sup id="w118g1-7">[[7]](#w118b1-7)</sup>，粢食不凿<sup id="w118g1-8">[[8]](#w118b1-8)</sup>，昭其俭也；衮冕黻珽<sup id="w118g1-9">[[9]](#w118b1-9)</sup>，带裳幅舄<sup id="w118g1-10">[[10]](#w118b1-10)</sup>，衡紞纮綖<sup id="w118g1-11">[[11]](#w118b1-11)</sup>，昭其度也；藻率鞞鞛<sup id="w118g1-12">[[12]](#w118b1-12)</sup>，鞶厉游缨<sup id="w118g1-13">[[13]](#w118b1-13)</sup>，昭其数也；火龙黼黻<sup id="w118g1-14">[[14]](#w118b1-14)</sup>，昭其文也；五色比象<sup id="w118g1-15">[[15]](#w118b1-15)</sup>，昭其物也；钖鸾和铃<sup id="w118g1-16">[[16]](#w118b1-16)</sup>，昭其声也；三辰旂旗<sup id="w118g1-17">[[17]](#w118b1-17)</sup>，昭其明也。夫德，俭而有度，登降<sup id="w118g1-18">[[18]](#w118b1-18)</sup>有数。文物以纪之，声明以发之，以临照百官，百官于是乎戒惧，而不敢易纪律。今灭德立违，而置其赂器于大庙，以明示百官。百官象<sup id="w118g1-19">[[19]](#w118b1-19)</sup>之，其又何诛焉？国家之败，由官邪也；官之失德，宠赂章<sup id="w118g1-20">[[20]](#w118b1-20)</sup>也。郜鼎在庙，章孰甚焉?武王克商，迁九鼎<sup id="w118g1-21">[[21]](#w118b1-21)</sup>于雒邑<sup id="w118g1-22">[[22]](#w118b1-22)</sup>，义士犹或非之，而况将昭违乱之赂器于大庙。其若之何?”公不听。

> 臧哀伯规劝桓公说：“作百姓君主的人，要发扬德行，堵塞违礼的行为，以便监察百官，就这样还怕有不足之处，还要显示各种美德以传示子孙。所以那清静肃穆的太庙用茅草做屋顶，祭祀天地的车子用草席做垫子，祭祀用的肉汁不用五味调和，黍稷、糕饼等祭品不用舂过的好米，这些是为了显示节俭。祭祀的礼服、礼冠，蔽膝、大圭，腰带、裙子、绑腿、靴子、冠上的横簪、冠旁的填绳、系冠的带子、冠顶的盖版，这些是为了显示等级上的差别。玉垫、刀饰、革带、带穗、旌旗上的飘带、马颈上的革带，这些是为了显示礼数上的差别。礼服上火形、龙形、斧形、弓形等花纹，这些是为了显示纹彩上的差别。用五色绘出各种图象来装饰器物服饰，这是为了显示器物物色的差别。马铃、大小车铃、旗铃，是为了显示声音节奏，旌旗上画的日、月、星辰，是为了显示光明。所谓德行，就是节俭而有法度，事物的增减都有一定的数量，并用纹彩和颜色加以标志，用声音和光亮加以表现，以此来监察百官，百官这才警戒畏惧，而不敢违反法度。现在君王毁灭德行，树立违礼的坏榜样，把别国贿赂的宝器安放在太庙里，以此明白昭示百官。百官都来效法，君王又用什么去惩罚他们呢？国家的衰败，是由于官吏不走正道。官吏丧失德行，则是由于国君宠爱和贿赂风行的原故。郜鼎放在鲁国的太庙，还有比这更公开的贿赂吗？武王打败殷商，将九鼎搬到王城，义士尚有批评他的，更何况将标志违礼作乱的贿赂之器放在太庙，又该怎么样呢？”桓公不听。

- <b id="w118b1-3">[[3]](#w118g1-3)</b> 临照：管理和监察。临，统管，治理。照，察看。
- <b id="w118b1-4">[[4]](#w118g1-4)</b> 德：美德。
- <b id="w118b1-5">[[5]](#w118g1-5)</b> 清庙：即祖庙，因其肃穆清静，故称。
- <b id="w118b1-6">[[6]](#w118g1-6)</b> 大路：也作“大辂”，即大车，特指天子或诸侯国国君祭天时所乘的车子。越（huó）席：用蒲草编织的席子。越，通“括”，束，结。
- <b id="w118b1-7">[[7]](#w118g1-7)</b> 大（tài）羹：即太羹，也作“泰羹”，古代祭祀时所用的肉汁。不致：指不调五味，不加各种作料。
- <b id="w118b1-8">[[8]](#w118g1-8)</b> 粢（zī）食（sì）：用黍稷加工品制作的饼食，祭祀用作供品。粢，黍稷，泛指谷类粮食。不凿（zuò）：不舂，这里指不精细加工。
- <b id="w118b1-9">[[9]](#w118g1-9)</b> 衮（ɡǔn）：古代帝王及公卿祭祀宗庙时所穿的礼服。冕（miǎn）：古代帝王、公卿、诸侯所戴的礼帽。黻（fú）：通“韨”，古代用做祭服的熟皮制蔽膝。珽（tǐnɡ）：古代君臣在朝廷上相见时所持的玉制朝板，即玉笏（hù）。
- <b id="w118b1-10">[[10]](#w118g1-10)</b> 带：指束在腰间的革带，皮带。裳（chánɡ）：古代男女穿的裙式下衣。幅(bī)：古代自足至膝斜缠在小腿部的帛条或布条，形似如今的绑腿。舄（xì）：双底鞋，着地的一层为木底，这里泛指鞋子。
- <b id="w118b1-11">[[11]](#w118g1-11)</b> 衡：把冠冕稳定在发髻上的横簪。紞（dǎn）：古代垂在帽子两旁用以悬挂塞耳用的玉瑱（tián）的带子。纮（hónɡ）：古代冠冕系在颔下的带子。古人戴冠冕时，先用簪子别在发髻上，再用纮挽住，系在簪子的两端。綖（yán）：古代覆在冠冕上的一种长方形饰物，以木板为干（ɡàn），外包黑色布帛。
- <b id="w118b1-12">[[12]](#w118g1-12)</b> 藻：一种用来放玉的木垫儿，外包熟皮，并绘有水藻形图案。率：通“帅”，佩巾。鞞（bǐnɡ）鞛（běnɡ）：佩刀刀鞘饰物，上饰为鞞，下饰为鞛。
- <b id="w118b1-13">[[13]](#w118g1-13)</b> 鞶（pán）：绅带，又名“大带”，束衣用。厉：下垂的大带。或谓“鞶厉”：是一个词，指束腰革带与革带下垂的部分。游（liú）：同“斿”，古代旗帜上下垂的饰物。缨：套在马胸部的革带，即马鞅。数：表示尊卑制度的礼数。
- <b id="w118b1-14">[[14]](#w118g1-14)</b> 火龙黼（fǔ）黻（fú）：都是古代礼服上所绣的花纹，如火形者为“火”，如龙形者为“龙”，黑白色相间如斧形者为“黼”，黑青色相间如“亚”形者为“黻”。
- <b id="w118b1-15">[[15]](#w118g1-15)</b> 五色：指青、赤、黄、白、黑五种颜色。比象：指比照天地万物所画出的各种图像。
- <b id="w118b1-16">[[16]](#w118g1-16)</b> 钖（yánɡ）鸾和铃：都是系在车马和旗帜上的铃铛，系在马额头上的叫“钖”，系在马嚼子上的叫“鸾”，系在车前用作扶手的横木上的叫“和”，系在绘有龙形图案的旗帜竿头的叫“铃”。
- <b id="w118b1-17">[[17]](#w118g1-17)</b> 三辰：指日、月、星。旂（qí）：旗面绘有龙形图案，竿头系有小铃铛的旗子。
- <b id="w118b1-18">[[18]](#w118g1-18)</b> 登降：增减。登为增，降为减。有数：指有节度、节制。（注意此处的“数”字与上文“昭其数也”句的“数”字在词义上的区别。）
- <b id="w118b1-19">[[19]](#w118g1-19)</b> 象：同“像”，法式，式样，这里是榜样的意思。
- <b id="w118b1-20">[[20]](#w118g1-20)</b> 章：明显。与下文“章孰甚焉”句之“章”义同。
- <b id="w118b1-21">[[21]](#w118g1-21)</b> 九鼎：相传为夏禹所铸，用以象征九州。夏、商、周三代都把它作为政权的象征，成为传国之宝。
- <b id="w118b1-22">[[22]](#w118g1-22)</b> 雒（luò）邑：也作“洛邑”，东周都城所在，相传周武王克商后由周公姬旦营建，其故地见《周郑交质》一文的题解。

周内史闻之，曰：“臧孙达其有后于鲁乎！君违，不忘谏之以德。”

> 周朝的内史听到这件事，说：“臧孙达的后代大概在鲁国世代享受爵禄吧！国君违礼，他不忘用德行加以规劝。”
