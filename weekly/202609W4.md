### 1. ZIP、7z、XZ 介绍

可以把 **ZIP、7z、XZ** 先理解成三种不同层次的东西：

* **ZIP**：一种“压缩包格式”，里面可以放多个文件，每个文件通常独立压缩。
* **7z**：一种“压缩包格式”，设计目标是高压缩率，常用 **LZMA/LZMA2**。
* **XZ**：一种“单文件压缩格式”，核心也是 **LZMA2**，通常用于压缩 `.tar` 之类的文件。

真正决定“怎么压缩”的，主要是里面使用的**压缩算法**。

#### 1. 先理解压缩的核心：重复数据

例如：

```text
abcabcabcabcabcabc
```

直接存储需要很多字节。

压缩算法会发现：

```text
abc
```

重复出现了很多次，于是可以表示成类似：

```text
abc × 6
```

实际算法当然比这个复杂很多。

主流无损压缩基本可以拆成两类思想：

##### 第一类：找重复

例如：

```text
ABCDEFGABCDEFGABCDEFG
```

发现后面的内容和前面已经出现过。

于是可以记录：

```text
复制前面距离 7 个字节的位置，长度 14
```

这就是 **LZ 系列算法**的核心思想。

##### 第二类：让高频数据用更短的编码

假设数据中：

```text
A 出现 70%
B 出现 20%
C 出现 10%
```

那么没必要给 A/B/C 都分配同样长度的编码。

可以：

```text
A -> 0
B -> 10
C -> 11
```

这类思想就是 **Huffman / Range Coding / Arithmetic Coding** 等熵编码。

所以现代压缩算法经常是：

```text
找重复
   ↓
转换成更容易压缩的形式
   ↓
熵编码
   ↓
压缩数据
```

#### 2. ZIP

ZIP 本质上是一个**容器格式**。

最常见的压缩算法是：

> **DEFLATE = LZ77 + Huffman**

可以粗略理解成：

```text
原始数据
   ↓
LZ77 找重复
   ↓
(length, distance)
   ↓
Huffman 编码
   ↓
压缩数据
```

例如：

```text
hello hello hello hello
```

LZ77 会尝试把重复部分表示成：

```text
hello
<重复之前的数据>
<重复之前的数据>
<重复之前的数据>
```

然后 Huffman 再进一步压缩这些符号。

##### ZIP 的一个重要特点

ZIP 通常是：

```text
ZIP
├── a.txt → DEFLATE
├── b.txt → DEFLATE
├── c.jpg → DEFLATE
└── d.exe → DEFLATE
```

每个文件可以独立压缩。

所以：

```bash
zip archive.zip a.txt b.txt c.txt
```

本质上是在 ZIP 容器里保存多个压缩成员。

##### 优点

* 历史悠久
* 支持非常广
* Windows/macOS/Linux 基本都支持
* 可以随机提取其中某个文件

##### 缺点

DEFLATE 的压缩率已经不算特别高。

#### 3. 7z

7z 是一种**压缩容器格式**。

它最常见的核心算法：

> **LZMA / LZMA2**

可以简单理解成：

```text
7z
 ↓
LZMA/LZMA2
 ↓
字典匹配 + Range Coding
```

LZMA 的核心仍然是：

> **大量寻找之前出现过的重复数据。**

但它的字典通常可以非常大。

例如：

```text
AAAAAAAA........
```

或者：

```text
某个大型项目中反复出现的代码/文本
```

如果这些重复内容距离很远：

```text
A ................. A
```

LZMA 可以利用较大的字典找到它们之间的关系。

##### LZMA 为什么压缩率通常比 DEFLATE 高？

可以简单理解成：

```text
DEFLATE
字典相对较小
+
LZ77
+
Huffman
```

而：

```text
LZMA
更大的字典
+
更复杂的匹配模型
+
Range Coding
```

因此 LZMA 可以更努力地寻找重复。

代价就是：

```text
压缩：
CPU ↑
内存 ↑
时间 ↑

解压：
通常也比 ZIP 稍重
```

所以 7z 经常适合：

> **我不太在乎压缩时间，希望文件尽可能小。**

#### 4. XZ

XZ 和 7z 有一个非常有意思的关系。

XZ 通常使用：

> **LZMA2**

所以可以粗略理解：

```text
7z ──→ 常用 LZMA/LZMA2
          ↑
          │
XZ ───────┘
```

但它们不是同一个文件格式。

例如：

```text
xxx.7z
```

是一个**归档/压缩容器**。

而：

```text
xxx.xz
```

更像是：

> **把一个数据流压缩起来。**

所以 Linux 中经常看到：

```text
xxx.tar.xz
```

其实是：

```text
很多文件
   ↓
tar
   ↓
xxx.tar
   ↓
xz / LZMA2
   ↓
xxx.tar.xz
```

也就是说：

**tar 负责“打包”，xz 负责“压缩”。**

#### 5. 为什么 Linux 特别喜欢 `.tar.xz`？

因为 UNIX/Linux 很喜欢把：

> **打包和压缩分开处理。**

例如：

```bash
tar -cf source.tar source/
```

先打包：

```text
source/
├── a.c
├── b.c
├── c.h
└── README
       ↓
source.tar
```

然后：

```bash
xz source.tar
```

得到：

```text
source.tar.xz
```

所以：

```text
tar = 打包
xz  = 压缩
```

而 ZIP/7z 通常把：

```text
打包 + 压缩
```

放在一个格式里面。

#### 6. 三者放一起比较

|      | ZIP            | 7z                  | XZ           |
| ---- | -------------- | ------------------- | ------------ |
| 本质   | 压缩包格式          | 压缩包格式               | 压缩格式         |
| 常见算法 | DEFLATE        | LZMA/LZMA2          | LZMA2        |
| 核心思想 | LZ77 + Huffman | LZMA + Range Coding | LZMA2        |
| 压缩率  | 中等             | 较高                  | 较高           |
| 压缩速度 | 较快             | 较慢                  | 较慢           |
| 解压速度 | 较快             | 中等                  | 中等           |
| 内存需求 | 较低             | 较高                  | 较高           |
| 多文件  | 原生支持           | 原生支持                | 通常需要 tar     |
| 常见场景 | 通用文件交换         | 高压缩率归档              | Linux 软件包/源码 |

#### 7. 一个很重要的区别：压缩 ≠ 打包

这是理解 ZIP / 7z / XZ 最关键的一点。

例如有：

```text
a.txt
b.txt
c.txt
```

##### ZIP

```text
           ZIP
       ┌────┼────┐
       ↓    ↓    ↓
     a.txt b.txt c.txt
       ↓    ↓    ↓
     压缩  压缩  压缩
```

ZIP 同时承担：

```text
打包 + 压缩
```

##### 7z

类似：

```text
             7z
       ┌──────┼──────┐
       ↓      ↓      ↓
      a.txt  b.txt  c.txt
         ↓    ↓    ↓
          LZMA/LZMA2
```

也是：

```text
打包 + 压缩
```

##### tar.xz

则是：

```text
a.txt ─┐
b.txt ─┼→ tar → tar.xz → xz
c.txt ─┘
```

这里：

```text
tar = 打包
xz  = 压缩
```

#### 8. 最后用一句话记忆

你可以直接这样记：

```text
ZIP = DEFLATE = LZ77 + Huffman
```

```text
7z = 容器 + LZMA/LZMA2
```

```text
XZ = LZMA2 压缩流
```

而底层核心思想其实都可以归结到：

```text
寻找重复
   ↓
用“引用”代替重复数据
   ↓
统计概率
   ↓
高频内容用更短编码
   ↓
得到压缩数据
```
